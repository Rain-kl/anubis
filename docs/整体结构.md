2. 核心模块职责

2.1 命令行入口 (cmd/anubis)

• 参数解析：处理命令行参数与环境变量

• TLS配置：证书与反向代理设置

• 策略加载：从文件系统加载策略配置

• 服务组装：构建中间件链 + 核心Server

• HTTP服务启动：监听指定端口

2.2 核心逻辑层 (lib/)

config.go
• 策略文件加载与验证

• HTTP路由注册（API/静态资源/挑战处理）

anubis.go - 核心判定引擎
• 策略评估与决策

• DNSBL查询处理

• 挑战签发与校验

• JWT与Cookie管理

http.go - HTTP协议层
• 请求路由分发

• 页面渲染与重定向

• 安全校验与Cookie操作

子模块：
• policy/：策略语义解析、阈值规则、Bot规则匹配

• challenge/：PoW、metarefresh等挑战算法

• store/：挑战状态、缓存、DNSBL存储抽象

• localization/：多语言文案管理

• thoth/：Thoth IP信誉库对接（可选）

2.3 内部工具层 (internal/)

• headers.go：IP地址处理（X-Real-IP, X-Forwarded-For）

• ja4h.go：JA4H HTTP指纹生成

• dnsbl/：DroneBL查询实现

• ogtags/：Open Graph标签透传缓存

• honeypot/：诱捕器实现（流量评分）

3. 请求处理流程

3.1 主请求处理链


HTTP Server 入口 (main.go)
↓
全局中间件链：
  - CustomRealIPHeader (自定义IP头处理)
  - RemoteXRealIP (RemoteAddr转X-Real-IP)
  - XForwardedForToXRealIP (XFF补充X-Real-IP)
  - XForwardedForUpdate (清洗XFF链)
  - JA4H (注入HTTP指纹)
↓
核心 Server (lib.Server) → ServeHTTP
↓
静态资源处理 (/static/, /xess/)
↓
robots.txt (可选)
↓
其他请求 → maybeReverseProxyOrPage


3.2 策略评估流程 (anubis.go)

check() 流程：
1. 获取客户端IP (X-Real-Ip)
2. 策略匹配 (policy.Bots规则)
   - Allow/Deny/Challenge/Weigh/Benchmark
3. 阈值计算 (policy.Thresholds)
4. DNSBL检查 (可选)
5. 规则执行：
   - Allow → ServeHTTPNext (直通后端)
   - Deny → 拒绝页面
   - Challenge → 挑战流程
   - Benchmark → 基准测试页面
6. Cookie/JWT校验：
   - 有效 → ServeHTTPNext
   - 无效/过期 → 挑战页面


3.3 最终转发

• 配置上游：反向代理到 target

• 无上游：返回静态页面或重定向

4. 辅助功能

4.1 其他入口

• Metrics端口：独立HTTP Server，默认9090

• API路由：

  • /_anubis/pass-challenge - 挑战通过

  • /_anubis/check - 状态检查

  • /_anubis/honeypot/... - 诱捕器

• 静态资源：/_anubis/static/

4.2 网络配置

• 主监听：-bind (默认:8923)

• 网络类型：-bind-network (tcp/unix)

• Metrics监听：-metrics-bind (默认:9090)

4.3 反向代理

• 目标：-target (默认: localhost:3923)

• Host头：-target-host 强制设置

• TLS SNI：-target-sni (auto/指定值)

• 安全选项：跳过TLS验证、禁用keep-alive

• 路径处理：-strip-base-prefix 剥离前缀

5. 关键配置项

5.1 基础配置

• 基础路径：-base-prefix (如 /myapp)

• 公开URL：-public-url (构建redirect用)

5.2 安全与挑战

• 策略文件：-policy-fname (默认内置)

• 挑战难度：-difficulty

• 调试模式：-debug-benchmark-js

• JWT难度：-difficulty-in-jwt

5.3 Cookie/JWT

• Cookie前缀：-cookie-prefix

• 域名设置：-cookie-domain / -cookie-dynamic-domain

• 有效期：-cookie-expiration-time

• 安全属性：Partitioned, Secure, SameSite

• 签名密钥：HS512或Ed25519私钥

5.4 IP处理

• RemoteAddr：-use-remote-address (直连必开)

• XFF清洗：-xff-strip-private 剥离私有IP

• 自定义IP头：-custom-real-ip-header

5.5 其他功能

• Open Graph：透传缓存配置

• DNS/反爬：robots.txt、管理员邮箱

• 语言设置：强制语言、简化文案

• Thoth集成：IP信誉库配置

6. 部署与运行

6.1 运行方式

# 直接运行
./anubis -bind :8923 -target http://localhost:3923

# 健康检查
./anubis -healthcheck

# 导出资源
./anubis -extract-resources


6.2 配置示例

./anubis \
  -bind :8923 \
  -target http://localhost:3923 \
  -policy-fname my-policy.yaml \
  -cookie-secure true \
  -cookie-same-site Lax \
  -difficulty 5


7. 扩展开发

7.1 自定义策略

编辑 data/botPolicies.yaml 或指定外部策略文件：
bots:
  - name: "allow-bots"
    user_agent: ["Googlebot", "Bingbot"]
    action: allow

  - name: "challenge-suspicious"
    user_agent: ["*"]
    action: challenge
    difficulty: 3


7.2 添加新挑战算法

在 lib/challenge/ 下实现：
type Challenge interface {
    Generate(ctx context.Context, req *http.Request) (ChallengeData, error)
    Validate(ctx context.Context, req *http.Request, data ChallengeData) (bool, error)
}


7.3 自定义中间件

在 internal/ 添加新中间件：
func MyMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        // 预处理逻辑
        next.ServeHTTP(w, r)
        // 后处理逻辑
    })
}
